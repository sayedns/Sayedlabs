## Before publishing
1. Replace placeholder people initials with real headshots.
2. Replace the cropped mockup hero asset with a final lab-owned scientific image.
3. Add verified external links (Stanford profile, PubMed, Google Scholar, ORCID).
4. Review Stanford Medicine brand/logo usage before using official Stanford marks.
5. Add analytics, accessibility checks, favicon, and final SEO metadata.
6. Host on your preferred platform (Stanford Sites, GitHub Pages, Netlify, Vercel, or another static host).
